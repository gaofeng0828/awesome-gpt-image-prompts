Direction A

Editorial Magazine

Warm, literary, sophisticated
Vibe: Pentagram meets It's Nice That
Type: DM Serif Display headings + DM Sans body
Color: Warm off-white #FAFAF8, charcoal text, no bright accents
Layout: Mixed card sizes, featured hero card, generous padding
For you: The prompts read like articles — literary, intentional, collectible. Best if your audience values taste and curation.

Direction B

Museum Gallery

Minimal, contemplative, art-forward
Vibe: MoMA meets Fondation Beyeler
Type: DM Sans 300 ultra-light headings, small-caps labels
Color: Pure white #FFFFFF, minimal UI chrome
Layout: Single column, generous vertical space, images centered like art on walls
For you: Each prompt is an exhibit. Maximum focus on the image. Best for a contemplative browsing experience.

Direction C

Swiss Data Grid

Structured, dense, information-first
Vibe: Are.na meets Bloomberg Terminal
Type: JetBrains Mono throughout, data-forward
Color: Cool grey #F7F7F5, tabular borders, black active states
Layout: Tight uniform grid, all cards same size, category badges, ID numbers
For you: Every prompt is a data point. Best for power users who want to scan, filter, and copy fast. Scales well to 100+ cases.
